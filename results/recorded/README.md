# Recorded academic run

These eleven CSVs and `report_data.json` are the original notebook exports. The eleven PNGs are the saved notebook figure outputs. The manifest identifies the input notebook, report, dataset and individual output bytes by SHA-256. Its notebook cell indices are zero-based positions in the supplied source notebook.

The comparison values in the main README come from this directory. New runs produce their own CSVs and figures in a separate output directory. The archived degree histogram's final bin also includes degree 30, despite its original “1–29 shown” label. Fresh histograms label and plot degrees 1–30 explicitly.
